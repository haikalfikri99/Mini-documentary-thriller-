# Pewarnaan tangan (hand-tint) #009
Zona warna kasar per gambar AI (`<label>.json`, koordinat 0..1). `kit/collage/handtint.py ai/<label>.jpg tint/<label>.json` → `ai/<label>.tint.png` (RGB warna + A kekuatan), dibaca `bk.cut(..., tint_map=...)`.
Palet tinta cat air (muted, gaya cetakan berwarna tangan abad 19): roti #D8A35A · selada #8DAA5B · tomat #C9583F · keju #E9C24E · daging #7B4A2C.
Hanya objek makanan hero (#009 burger). Kode warna §K (merah stempel = ancaman, biru arsip = sistem, kuning = sorotan) tetap untuk elemen kode; tint makanan sengaja redup supaya tidak bertabrakan.
