# Mini Thriller IDN — workflow produksi (gaya ARSIP Kolase sejak #003)
**Real Stories. Unexpected Truths.** Satu video = satu kasus nyata, dibuka sebagai **ARSIP KASUS**, 40–60 dtk, 9:16. **Contoh lengkap terbaru: `stories/micin/` (#003)**. Gaya, pipeline, dan komponen tetap tidak didesain ulang per episode; episode hanya mengisi cerita, gambar arsip, shot, dan cue. Perubahan gaya hanya lewat `references/6-pelajaran.md` (butuh bukti atau keputusan user).

## Aturan tetap (keputusan user)
- **Kebenaran:** dramatisasi penyajian, jangan mengarang bukti; klaim penting ≥ 2 sumber; klaim yang diperdebatkan disebut "mengaku … dibantah".
- **Visual:** gaya **ARSIP Kolase** (`kit/styles/arsip-kolase/STYLE.md`): cetakan arsip asli (domain publik/CC0/CC BY) dipotong di meja kertas + benda yang kita cetak sendiri dengan kode + elemen vektor minimal (panah, garis putus-putus, garis ukur) **hanya bila membantu cerita**. Layar tidak boleh penuh: ±5–6 potongan per frame, teks layar hanya stempel/label/angka.
- **AI:** gambar AI **boleh bila perlu** (benda yang tidak ada arsipnya), lebih utama arsip asli; **video dari model AI tidak dipakai**. Tanpa stock footage. Musik/SFX dibuat dengan kode (FluidR3 MIT + sintesis).
- **VO:** ElevenLabs, suara Saos Cocol (`R86jddkroI9bJwXFfjsr`), `eleven_v4`, prompt bertag; Claude generate lewat konektor ElevenLabs (tanya dulu: memakai kredit user); #004 user generate manual di ElevenLabs → Claude mengirim **script bersih + prompt bertag + settingan** dalam satu paket (`audio/vo_prompt_elevenlabs.md`), user mengunggah mp3 ke chat; bila konektor/kuota gagal user generate manual dan menaruhnya di Drive. Isi VO tidak diubah setelah disetujui; boleh diproses (rapatkan jeda, atempo ringan ke 2,6–2,7 kata/dtk).
- **Komposisi konten (`research/niche/KEPUTUSAN_RISET.md`):** pilar ±70% = **"alasan ASLI di balik benda, tempat, harga, dan merek yang kamu kenal, terutama di Indonesia"**; peristiwa/hal yang dikenal penonton boleh ditambah bila menarik (keputusan user 14 Nov). Selingan ±30%: **W4 keputusan fatal** (±20%) + **W6 sejarah & tempat** (±10%), W1/W5 sesekali; **W3 misteri, klenik, kasus pidana berjalan = tidak dipakai**. Ide: `research/niche/BANK_IDE.md`, `RISET_SELINGAN.md`.
- **Target produksi: 1 video/hari.**
- **Model & effort:** sesi utama (kode film, keputusan kreatif) = Opus dengan **effort high** (arahan lemo-opuscar; user mengatur `/effort high`). Subagen dipilih Claude sesuai kesulitan: Haiku = mekanis (unduh, cek file), Sonnet = riset terstruktur (cari gambar, data), Opus = penilaian kreatif sulit.
- **Rantai shortlist → judul → hook → cover → alur menahan penonton: baca `references/8-hook-dan-judul.md` sebelum shortlist dan sebelum script.** Fakta benar, kemasan semaksimal mungkin; benda/merek dikenal + klaim di kata 1–3; angka/uang/KAPITAL di judul; jawaban bertahap + loop bertumpuk; janji pilar dibayar; uji POV penonton baru.
- **Batasan tetap sesi:** YouTube memblokir pengambilan otomatis dari server (jangan ditembus; riset memakai data yang sudah ada). Apify hanya dipakai bila user menyetujui dan dengan batas biaya (riset tempo VO #004 selesai, US$1,50). Generate ElevenLabs memakai kredit user → tanya dulu. Wikimedia: satu permintaan/detik, hormati 429. Tanpa logo/foto bermerek asli, tanpa video AI, tanpa stock footage.
- **Pengingat model/effort:** di awal episode baru ingatkan user kapan harus Opus + effort high (script final, keputusan kreatif, kode film); riset dan fact sheet cukup Sonnet. Subagen memakai model sesuai tugas (CLAUDE.md).
- **Pengingat `/compact` / `/clear` (wajib, user meminta):** di tiap titik di tabel "Titik ingat" bawah, Claude menulis catatan "Lanjut setelah /compact" di `stories/<slug>/README.md`, commit + push, lalu **mengatakan jelas di akhir balasan**: "Silakan `/compact` sekarang" (atau `/clear`) + kalimat apa yang diketik setelahnya. Ingatkan juga bila konteks terasa berat di luar titik itu (banyak gambar/tangkapan layar, keluaran alat panjang, >3 putaran revisi).
- Jawab dalam bahasa Indonesia, lugas, kritis, beri rekomendasi; minim beban CLI untuk user. Claude tidak bisa mendengar: audio dicek dengan alat dan dilaporkan apa adanya.
- Commit/push ke branch sesi; tanpa PR kecuali diminta; `main` hanya diperbarui atas izin user.

MP4 final boleh di-cross-post ke TikTok/Reels sebagai laboratorium drop-off, bukan sumber uang (#55).

# 1. Cerita dan Script
Gabungan: konsep editorial channel dari user (positioning, 6 wilayah cerita, aturan faktual, seleksi 5 kriteria, framework 6 babak, 8 prinsip), riset data nyata (`research/niche/`), dan skill `hook-and-headline-writing`, `youtube-shorts`, `fact-checking`. Setiap video wajib lolos panduan ini **sebelum VO direkam**.

## A. Identitas editorial
**Mini Thriller IDN — Real Stories. Unexpected Truths.**
*Cerita nyata yang lebih mengejutkan daripada yang terlihat.*
Janji: setiap video membawa penonton masuk ke sebuah cerita nyata, mengungkap sesuatu yang tidak diketahui, lalu memberi payoff yang membuat mereka melihat dunia dengan cara berbeda.
- Channel ini **bukan** channel bencana saja; bencana hanya salah satu wilayah. Jangan biarkan satu wilayah mendominasi.
- **ARSIP KASUS** = perangkat seri visual untuk semua wilayah (setiap video = satu "kasus" yang dibuka), bukan pembatas topik.
- Channel ini terpisah dari "Ruang Cermat" (keputusan user): identitas, aset, dan topik tidak dicampur.

## C. Aturan faktual: factual storytelling, bukan fiction
**Dramatize the presentation, never fabricate the evidence.**
| Boleh | Tidak boleh |
|---|---|
| Membangun ketegangan lewat narasi | Mengarang kejadian |
| Rekonstruksi visual (ilustrasi jelas, bukan foto palsu) | Menyajikan rekonstruksi sebagai rekaman/arsip asli |
| Metafora visual | Membuat bukti palsu |
| Mengatur ulang penyajian fakta agar menarik | Mengubah kronologi hingga menyesatkan |
| Menyederhanakan fakta ilmiah | Membesar-besarkan kesimpulan penelitian |
| Dialog ilustratif **dengan label** ("ilustrasi") | Mengarang kutipan tokoh nyata |

Contoh: "Sebuah kapal ditemukan tanpa awak." Boleh: "Ketika kapal itu ditemukan, ada sesuatu yang tidak masuk akal. Tidak ada seorang pun di atasnya." Tidak boleh: "Kapten terakhir kali terlihat berlari sambil berteriak…" bila tidak ada bukti.
- Klaim penting ≥ 2 sumber kredibel independen; utamakan sumber primer (dokumen resmi, penelitian ilmiah, laporan investigasi, arsip sejarah).
- Kasus yang masih diperdebatkan **wajib** menyebut ketidakpastiannya ("teori yang paling banyak diterima…", "tidak ada yang tahu pasti…").
- Angka yang berbeda antar sumber: tampilkan yang disepakati saja (film #001: hanya "+4°C").
- Jangan mengaku sudah membaca sumber yang tidak dibuka.

**Protokol anti-halusinasi 2 lapis (v5.0).** Fact sheet (`stories/<slug>/README.md`) dan `kolase/SOURCES.jsonl` memuat: **lapis lokal** = ≥ 2 sumber yang membuktikan peristiwa/putusan/fenomena di Indonesia; **lapis mekanisme/primer** = ≥ 1 putusan, dokumen, atau penelitian primer. Bila primer tidak terbaca (403/PDF, seperti putusan KPPU dan MA di #004), tulis "primer: tidak terbaca" di fact sheet, batasi klaim pada yang dilaporkan sumber lokal, dan ucapkan sebagai "menurut KPPU/laporan …"; jangan menyimpulkan alasan hakim atau status pembayaran. **Angka dan perbandingan:** dilarang mengarang angka/persentase; angka hanya ditulis bila eksplisit di sumber dan konsisten antar-sumber; bila sumber hanya menyebut arah ("lebih murah/mahal", "lebih sering dipilih") pakai perbandingan perilaku dan kontras konkret itu. **Pagar:** sebut status putusan/temuan lembaga, muat bantahan pihak terkait, tanpa logo merek asli, tahun kejadian di layar, stempel `bk.stamp(..., legible=True)`.
**Lokasi script resmi:** `stories/<slug>/README.md` (bagian "Paket final") dan `stories/<slug>/kolase/audio/script_vo.txt`. Tidak ada `SCRIPT.md`.

## D. Seleksi cerita (skor 1–5 per kriteria, produksi bila total ≥ 20 dan tidak ada nilai < 3)
**Urutan kerja (keputusan user):** tampilkan dulu shortlist judul + cerita singkat + wilayah + penilaian keseluruhan; user memilih; baru riset & fact-check judul terpilih. Jangan menghabiskan waktu riset sebelum ada pilihan. **Drama wajib:** harus ada taruhan nyata (nyawa, uang, kehilangan, bahaya yang mengancam penonton); ironi intelektual saja (contoh: kisah Gruen pencipta mal) dinilai dangkal oleh user.
| Kriteria | Pertanyaan |
|---|---|
| **Hook** | Apakah 2 detik pertama membuat orang berhenti? Bisa diucapkan satu kalimat yang terdengar mustahil? |
| **Evidence** | Ada sumber tepercaya (≥ 2, idealnya primer)? |
| **Conflict** | Ada masalah, risiko, atau pertentangan (manusia vs sistem/alam/keputusan)? |
| **Escalation** | Apakah ceritanya makin menarik di setiap langkah? |
| **Payoff** | Apakah ending memberikan jawaban atau kejutan yang memuaskan dan bisa didiskusikan? |
**Filter sebelum skor (sejak #004):** jalankan `kit/tools/riset_topik.py` dan terapkan `research/niche/topik/RUMUS_PEMILIHAN.md` (Permintaan, Celah, Lokal, Cerita, Bahan; gerbang Lokal ≥ 4, Celah ≥ 3, Cerita ≥ 3).
Tambahan: ada manusia untuk close-up; ada visual yang belum pernah dilihat orang; **Shock score** fakta (berapa persen penonton yang TIDAK tahu ini? kumpulkan 5–10 fakta ≥ 80 sebelum menulis).

## E. Apa yang membuat Shorts didistribusikan
Menurut konsep editorial kita (dirangkum user dari YouTube Help & wawancara kreator), YouTube membaca tiga kelompok sinyal:
1. **Appeal — STOP SWIPING:** hook, premis, visual pertama, ekspektasi penonton.
2. **Engagement — KEEP WATCHING:** durasi tonton, persentase ditonton, perkembangan cerita, pacing.
3. **Satisfaction — WORTH WATCHING:** payoff, kepuasan, respons penonton, keinginan kembali ke channel.

Yang terverifikasi (Studio → Analytics → Content → Shorts): **Viewed vs Swiped Away** ("berapa yang memilih menonton"), Engaged views, rata-rata durasi & persentase ditonton, retensi. YouTube **tidak** mempublikasikan ambang resmi; target 75–80% "viewed" hanyalah patokan kreator. Tidak ada formula yang terbukti menjamin viral — kita pakai prinsip yang didukung praktik kreator dan sinyal resmi, lalu uji dengan data channel sendiri.

## F. FORMULA ARSIP v5.0: terkunci (v4 13 Nov 2026 + revisi riset 13–14 Nov + pelajaran #004 + spesifikasi v5.0 14 Nov)

Motivasi penonton: aha/cara kerja + anggapan dibalik (menonton); musuh, perdebatan, pengalaman pribadi, kebanggaan lokal (berkomentar). "Melindungi diri" hampir tidak ada → jangan jadi sudut utama.

### F2. Lembar kerja (urut, jangan dilompati)
1. **Satu kalimat cerita:** "[Tokoh/objek] melakukan [X] dengan niat [Y], **tapi** [mekanisme tersembunyi], **maka** [akibat yang menyangkut penonton], dan [twist/pengakuan]." Tidak bisa ditulis = belum siap.
2. **Pertanyaan penonton:** satu pertanyaan di detik 3 yang **dijawab eksplisit**; tulis jawabannya satu kalimat yang bisa diceritakan ulang. Janji pilar ("alasan ASLI di balik hal yang kamu kenal") harus dibayar dengan satu kalimat yang menyentuh pengalaman penonton.
3. **Wilayah 2:** jawaban = mekanisme: psikologi, desain, uang.
4. **Daftar fakta** (maks 5 angka/klaim; sisanya ke deskripsi) dengan **protokol anti-halusinasi 2 lapis sumber** (C): ≥ 2 sumber lokal + ≥ 1 sumber mekanisme/primer. Yang tidak diketahui tidak diucapkan; yang diperdebatkan "kata X / dibantah".
5. **Tulis banyak varian hook** (F4), pilih satu; hook = judul = teks frame 0 = gambar frame 0.
6. **Tulis 6 segmen + 2 micro-rehook** (F3): tiga track sekaligus VO · teks layar · gambar. Pertanyaan eksplisit hanya di titik yang terdengar seperti akhir cerita (2–3 per video), dijawab setengah.
7. **Pass bahasa** (F5) + `humanizer`; **uji POV penonton baru**: siapa melakukan apa ke siapa, akibatnya apa; jargon dijelaskan; kata kerja punya objek. Baca keras dengan stopwatch.
8. **Scorecard** (F6) + gerbang (F7): semua lulus → kirim. Ada yang gagal → perbaiki beat itu saja.

### F3. Kerangka 6 segmen + 2 micro-rehook (v5.0; menggantikan 7 beat; 120–145 kata, 48–55 dtk @ 2,60–2,75 kata/dtk)
Kalimat pendek-menengah (6–13 kata) dengan tanda baca disiplin, supaya `kit/tools/line_starts.py` memecah VO menjadi ±18–24 shot (rata-rata 2,1–2,6 dtk/shot; gabung/potong manual bila hasilnya jauh dari itu).
| Segmen | ±Waktu (skala linier untuk 48–55 dtk) | Tugas | Aturan |
|---|---|---|---|
| 1 HOOK & ANOMALI | 0–4 dtk | **subjek dikenal + akibat berangka + sebab kecil/kontradiksi** ("Aqua didenda Rp13,8 miliar. Gara-gara warung kayak gini…") | konfirmasi judul; subjek di kata 1–3; kata tunjuk yang terhubung ke visual; selesai ≤ 4 dtk (≤ 14 kata); tanpa "Tahukah kamu" |
| 2A BUKTI AWAL / ATURAN MAIN | 4–16 | anggapan umum + mekanisme dasar dengan istilah sederhana ("Kok bisa?", "star outlet", harga lebih murah) | waktu/tempat hanya di layar; kartu ARSIP overlay; istilah dijelaskan lisan singkat |
| **MICRO-REHOOK 1** | ~16–18 | engsel pematah ekspektasi 3–6 kata ("Tapi ada satu syarat.") | pendek, tanpa jeda panjang |
| 2B BEDAH INTRIK / MEKANISME | 18–36 | bukti konkret (email, klausul, hasil eksperimen) + bantahan pihak lain + twist pertama; pertanyaan eksplisit hanya di titik yang terdengar selesai | gambar konkret; angka hanya bila membuka mata |
| **MICRO-REHOOK 2** | ~36–39 | pembalikan final 2–3 kata ("Aqua bebas? Belum.") lalu buka bukti pamungkas | jeda ≤ 0,3 dtk sebelumnya |
| 3–4 PAYOFF + CIRCULAR REFRAME LOOP | 39–54 | jawaban pilar eksplisit satu kalimat ("alasan ASLI") → punchline → penutup | bukan nasihat; **zero-CTA** |
**Pemetaan ke 7 beat lama** (data riset lama dalam F1 memakai istilah itu): beat 1 = segmen 1; beat 2–3 = 2A; beat 4–5 = 2B; beat 6 (TAPI/twist, ±65–75%) = micro-rehook 2 + bukti pamungkas; beat 7 = segmen 3–4.
**Penutup = Circular Reframe Loop (default, v5.0).** Kalimat terakhir **berdiri utuh** sebagai kesimpulan tajam atau pertanyaan reflektif (bukan kalimat menggantung yang harus disambung kalimat pertama), tetapi **memanggil ulang objek/situasi dari kalimat pertama** sehingga saat auto-replay, kalimat pembuka terdengar seperti bukti langsung. Ekor audio ≤ 0,15 dtk agar replay langsung menyambar frame 0 (`3-audio.md` §J). *Varian:* pertanyaan konkret ke pengalaman penonton tanpa memanggil objek pertama ("Warung dekat rumahmu jual merek apa aja?", dipakai #004; penutup pertanyaan 7/8 top di data transkrip, Circular Reframe Loop belum teruji di data kita sendiri: uji pertama di #005, catat stayed-to-watch dan replay). Jawaban bertahap + loop bertumpuk: `8-hook-dan-judul.md` §F. *Aturan "kalimat terakhir terpotong diselesaikan kalimat pertama" (loop jahitan gramatikal) dicabut 14 Nov 2026: belum pernah teruji dan terdengar dipaksa.*

### F4. Pola hook (pilih menurut jenis cerita; rumus lengkap `8-hook-dan-judul.md` §B)
0. **Subjek dikenal + akibat berangka + sebab kecil (utama, uang/denda/putusan/harga):** "[Merek] didenda [angka]. Gara-gara [hal kecil]." Angka/uang di judul +6,4/+8,6 poin breakout.
1. **Subjek dikenal + bantahan:** "Ini [benda]. Tapi [anggapan] itu salah." (Dyson 6,7 jt; "Perang ini cuma 40 menit" 4,3 jt)
2. **Pengakuan pembuat:** hanya dengan benda konkret di kata 1–3 (#002 gagal 37,2%).
3. **Kontradiksi:** "Banjir ini bukan datang dari sungai." (#001)
4. **Angka tak masuk akal / satu kesalahan kecil / yang tak seharusnya ditemukan.**
Lulus bila: spesifik, jujur (dibayar isi), terpahami **sekali baca/lihat**, bisa digambar satu frame, ≤ 12 kata.

### F5. Bahasa VO
- **Sapaan: "kamu" (orang kedua tunggal) dan "kita"**, natural dan konsisten dengan #001–#004; kasus harus terasa menyentuh dompet, kebiasaan, atau keputusan penonton hari ini. Nada investigatif tajam, lincah, sedikit jahil saat mengungkap ironi, berwibawa dan berbasis dokumen. Tanpa basa-basi pembuka ("Halo guys", "Tahukah kamu", "Pernahkah kalian berpikir") dan tanpa klise AI ("Di dunia yang serba cepat ini…", "Mari kita selami lebih dalam…").
- Lisan santai-sopan (bikin, nggak, ngaku, udah); kata yang paling dipahami penonton dan terbaca Whisper ("email", bukan "surel"; "nggak" pada narasi kasual). Kalimat 6–13 kata, satu kalimat = satu gambar; kata kerja aktif **dengan objek jelas**.
- **Nada:** santai, sedikit jahil, seperti teman yang baru tahu rahasia. Tanpa istilah bias/teori di depan. Lembaga/istilah dijelaskan ≤ 4 kata lisan ("KPPU, wasitnya persaingan bisnis"; "bintangnya dicopot", bukan "wholesaler").
- **Lisan dulu, uji mute, psikologi penonton** (`7-selera…` #60–#62): atribusi sekali di klaim sensitif saja; tiap kata kerja/lokasi punya objek atau nama jelas di caption; segmen tengah dan penutup menyentuh situasi harian penonton (dealer, HP murah, dapur rumah).
- Peran sebelum nama; ≤ 2 nama per video. Dilarang: "bukan X tapi Y", penutup fragmen yang mengulang, triad paksa, kata megah, statistik yang tidak dibutuhkan beat.
- Tanda baca = arahan baca (elipsis jeda berpikir, titik berhenti, satu kapital per video).
- **Tag ElevenLabs (Saos Cocol, eleven_v4)** hanya di titik perubahan emosi: [curious] hook · [warmly] setup · [mysteriously] TAPI · [serious] akibat · [pause][slowly] twist · [warmly] penutup. Dua take; cek pelafalan (KPPU per huruf, angka diucap penuh), durasi; tempo `3-audio.md` §I.

### F7. Gerbang 3 detik + rantai retensi
**Diagnosis #002 (37,2% stayed):** objek hook kabur, jeda 0,54 dtk di detik 2,4–3,0, kata kunci baru di 3,9–4,6 dtk, frame 0 gelap dan pelan, tanggal + nama asing di detik 4,6. Rubrik internal memberi 9/10: **data menang atas penilaian sendiri.**

|---|---|---|

Laporkan scorecard (16 baris) + gerbang H1–H7/R1–R6 ke user bersama script, lulus/gagal + catatan; H1/H3 dicek ulang dari `vo_words.json` setelah VO jadi.

## G. Prinsip pendukung
Concrete hook · curiosity gap kecil · eskalasi taruhan · information economy · variasi tempo (kalimat pendek setelah hening) · narasi dan visual saling melengkapi · emotional payoff · akhir yang menyisakan bahan diskusi. **Ketegangan butuh jeda**: beri 0,3–0,6 dtk sebelum reveal; bangun rasa penasaran, bukan kelelahan.

## H. Durasi
Gagasan dulu, lalu durasi terpendek yang lengkap. Patokan: wilayah 2 = 40–50 dtk (85–110 kata); cerita kejadian = 45–60 dtk. Galloway 2023 menemukan 50–60 dtk unggul di sampelnya: jangan memotong cerita yang butuh waktu, tapi jangan memanjangkan yang selesai di 40.

## I. Delivery & isi video (dari script ke film)
- **Satu kalimat = satu shot (1,5–2 dtk)**; potong di awal kata; tokoh berakting hanya bila mendukung kalimat (menoleh di hook, menunduk di penyesalan).
- **Teks layar** hanya untuk: hook (frame 0), stempel waktu/tempat, angka kunci, kutipan besar, label pilihan. Caption per kata menangani sisanya; jangan dobel dengan caption.
- **Kartu ARSIP KASUS** (templat) setelah hook; **set & prop** dari kit; satu sumber cahaya per shot.
- **Audio**: satu ide musik per babak; SFX untuk setiap kejadian di layar; dentuman besar di bawah 260 Hz atau di celah setelah kata (laporan per kata harus "none").

## J. Riset & fact-check (alur `fact-checking`)
1. Tulis klaim inti dan pertanyaan cerita. 2. Pecah script menjadi klaim tunggal (nama, tanggal, tempat, angka, sebab, kutipan). 3. Cari sumber primer + sekunder bereputasi, catat tautan & tanggal di `stories/<slug>/README.md`. 4. Beri status per klaim: terverifikasi / sebagian / diperdebatkan / tidak terverifikasi (dibuang). 5. Untuk sebab-akibat: pastikan sumber menyatakan sebab, bukan sekadar urutan. 6. Cek ulang visual yang memuat angka atau teks. 7. Catat ketidakpastian di script bila kasusnya masih diperdebatkan.

## K. Checklist sebelum VO direkam
- [ ] Scorecard F6 semua lulus dan sudah dilaporkan ke user
- [ ] Wilayah cerita jelas; rotasi terhadap 3 video terakhir; skor seleksi ≥ 20, tidak ada kriteria < 3
- [ ] Hook, judul, teks layar, dan frame 0 selaras
- [ ] Semua klaim ≥ 2 sumber, status dicatat; ketidakpastian disebut bila ada
- [ ] Prompt ElevenLabs bertag + target durasi tertulis di `audio/vo_prompt_elevenlabs.md`

## L. Belajar setelah tayang
Baca di Studio: Viewed vs Swiped Away (appeal), rata-rata % ditonton & grafik retensi (engagement), like/komentar/share/subscriber dan returning viewers (satisfaction). Diagnosis: swipe tinggi → hook/frame 0; turun di tengah → repetisi atau konteks hilang; retensi baik tapi interaksi lemah → payoff/echo. Jangan menyimpulkan dari satu video; ubah satu variabel besar per video; catat di README cerita. YouTube tidak memberi ambang resmi — bandingkan dengan video kita sendiri.

# 2. Visual dan Animasi — ARSIP Kolase (sejak #003, keputusan user 13 Nov 2026)

**Kenapa gaya ini:** data kita menunjukkan gaya animasi tidak membedakan performa (`research/niche/KEPUTUSAN_RISET.md`: 1.886 thumbnail, selisih ≈ 0); yang menentukan adalah isi frame 0 dan kecepatan produksi. User menolak tampilan 2D vektor buatan kode (terlalu sederhana); kolase cetakan arsip memberi detail kaya tanpa menggambar dari nol, cocok dengan merek ARSIP (kertas, stempel, slip ketik), dan cocok untuk "alasan asli di balik benda" (bukti visual). Gaya lama (2D ARSIP RIG, 3D) dihapus.

## A. Frame & tempo (Formula v4.1, terukur dari 11 rekaman pemenang)
1. **Frame 0 = benda pahlawan besar di tengah, sudah bergerak**; stempel/kata hook mendarat ≤ 0,2 dtk.
2. Satu kalimat VO = satu shot ±1,5–3 dtk; potongan baru atau gerak baru setiap ≤ 1 dtk. **Tidak ada momen layar kosong**: subjek shot ada sejak awal shot (slide ≤ 0,2 dtk), benda yang disebut belakangan boleh menyusul.
3. Benda pahlawan ≥ 45% lebar frame; teks layar ≥ 40 px dunia; satu subjek per frame; **±5–6 potongan maksimum**.
4. Zona: atas 0–150 kosong (UI), subjek y 150–1150, **pita caption y 1210–1536 bersih**, bawah = latar.
5. Teks layar = stempel, label, angka, slip ketik pendek. Kalimat yang sama dengan VO tidak ditulis ulang (caption sudah ada).
6. Loop: shot terakhir kembali ke komposisi frame 0.

## B. Bahasa visual (native moves)
Slap (ditepuk), slide (geser + overshoot), drop (jatuh memantul), pendulum (`putA`), **stempel** (`stampAt`: BODOH?, MUSUH, AMAN, TERUNGKAP, DIBANTAH), **ransom letters** untuk tahun/kata kunci, **slip mesin ketik** (`typed`), **data engraving** (batang gravir tumbuh, garis ukur), **map ARSIP** (`fileOverlay`, ≤ 1,3 dtk di awal setup), belah/potong (clip), coret/centang (`m_cross`, `m_tick_s`). Vektor minimal (`arrow`, `route`, `bow`): hanya untuk arah/aliran/ukuran yang sulit dipahami tanpa panah (berita menyebar, zat masuk ke ASI, ×10). Tinta gelap di atas latar terang; garis terang (`comp:'source-over'`) di atas latar gelap.

## C. Sumber gambar (urutan kerja)
1. Daftar benda per shot dulu (dari script); **cari hanya yang punya tempat di shot**, satu gambar terbaik per benda.
2. **Openverse** (`api.openverse.org/v1/images/?q=…&license=cc0,pdm,by`) — gratis, tanpa kunci, mengumpulkan Wikimedia/Met/NGA/rawpixel/Flickr Commons.
3. **Wikimedia Commons** (Pearson Scott Foresman "(PSF)" = garis bersih domain publik; Gray's Anatomy; Wellcome Collection = CC BY wajib kredit). API dibatasi kecepatan (HTTP 429): satu permintaan per detik, User-Agent generik; URL langsung `upload.wikimedia.org/wikipedia/commons/<a>/<ab>/<File>` (a/ab = md5 nama file) lebih ringan.
4. Tolak: clip-art modern, foto produk bermerek, foto orang modern yang bisa dikenali, lisensi BY-SA/tidak jelas, gambar dengan banyak teks di dalamnya.
5. Tidak ada arsipnya → gambar bergaya gravir (`kit/collage/engr_objects.py`, tambah fungsi baru ke pustaka) atau cetakan kita sendiri di `bake.py` (contoh: sachet MICIN, surat, koran). Gambar AI boleh bila tetap tidak ada, lalu diperlakukan sebagai cetakan (dipotong, diberi tinta). **Alur #004:** Claude menulis prompt (gaya gravir hitam-putih, latar polos/terang, tanpa logo/teks, tokoh konsisten per peran: pabrik = perusahaan, orang berjas generik = "pihak X", wasit berpolo gelap = KPPU) → user membuat di Google Flow → file ke `kolase/ai/` → `bake.py ai_to_raw()` → `prints.json` (`cut` dengan `tint_poly` bila sebagian gambar perlu diwarnai: bintang emas, kartu merah) → catat di `SOURCES.jsonl`. 6. Catat setiap file di `SOURCES.jsonl` (url, page, license, credit) → kredit CC BY masuk deskripsi YouTube.

# 3. Audio
Tanpa API key berbayar: musik = MIDI yang ditulis dengan kode lalu dirender fluidsynth + FluidR3_GM (MIT); SFX = disintesis numpy/scipy. **Kit:** `kit/audio/score_lib.py` (skor), `kit/audio/arsip_audio.py` (±35 SFX + `Mixer` standar), `kit/audio/vo_chain.py`, `kit/audio/check_audio.py`; episode hanya menulis not (`kolase/score_full.py`) dan aturan foley (`kolase/fullmix.py`). Contoh lengkap: `stories/micin/kolase/`.

## A. Prioritas (prinsip Murch): VO selalu nomor satu
**Rantai VO** (file asli tidak diubah):
1. High-pass 100 Hz (membuang dengung/rumble; VO film #001 punya dengung bass di 2,3 dtk pertama).
2. Leveller per frasa pada pita 300 Hz–4 kHz (jendela 300 ms, ±12 dB, celah sunyi dibiarkan), dihaluskan 250 ms.
3. Presence lift 2–5 kHz (+50%), lalu normalisasi ke −17 dBFS RMS.

**Latar menyingkir saat VO bicara:** envelope VO (attack 40 ms, release 250 ms) →
- musik: −6 dB tambahan + pita 1–4 kHz dikurangi 60%;
- SFX: pita 700 Hz–4,5 kHz dikurangi 70%.
Skor diset ±15 dB di bawah VO (`-32 dBFS RMS`) sebelum ducking.

**Ukur, jangan menebak:** `fullmix.py` mencetak level VO vs latar pada 300 Hz–4 kHz per bagian. Target ≥ 10 dB; momen benturan boleh ±7 dB asalkan dentuman ditaruh < 260 Hz atau tepat sesudah kata (contoh: "pecah").

## B. Skor per babak (MIDI)
Saluran GM yang dipakai: 44 tremolo strings, 61 brass, 47 timpani, 116 taiko, 55 orchestra hit, 49 slow strings, 8 celesta, 45 pizzicato, 43 contrabass, 58 tuba/low brass, 14 tubular bells, 10 music box. Kunci D minor.
| Babak | Musik |
|---|---|
| Hook | tremolo + brass & taiko di frame 1, roll timpani ke slam |
| Intro misteri | slam orchestra hit, drone D–Eb, swell low brass di kata kunci |
| Tempat & waktu | motif celesta polos di atas pizzicato "jam", satu nada sumbang saat tokoh menyadari ancaman |
| Pecah | tremolo naik, "ping" per kejadian, hentakan + jeda |
| Eskalasi | ostinato low strings 8th, timpani, stab brass tepat di kata kunci |
| Tanda bahaya | music box + string lembut, manis tapi janggal |
| Penyebab | denyut pizzicato makin keras, hit low brass per stempel |
| Korban | hampir sunyi, lonceng di angka |
| Penutup | motif polos kembali di atas disonansi, hit terakhir di kata terakhir |

## C. SFX (fungsi di `kit/audio/arsip_audio.py`)
`roar` (gemuruh: noise < 220 Hz + sub), `thud` (slam/stempel besar), `stampS`, `ping` (logam/paku), `crack` (kayu), `whoosh`, `boom` (ledakan), `screech` (logam bengkok), `groan` (tangki berderit), `gloop` (cairan kental), `plink` (tetes), `flip` (halaman), `air` (ambience), `horn` (kapal).
Sejak #003 waktu SFX diambil **otomatis** dari kejadian di layar (bagian G), bukan ditulis tangan.

## D. Loudness & mux
`loudnorm=I=-14:TP=-1:LRA=11` → hasil terukur ±−14,5 LUFS, peak −1 dBTP (cek: `ffmpeg -i f.mp4 -af ebur128=peak=true -f null -`). AAC 192 kbps, 48 kHz.

## E. QA audio tanpa telinga (`kit/audio/check_audio.py`)
Claude tidak bisa mendengar, jadi setiap mix dicek dengan alat dan hasilnya dilaporkan apa adanya:
1. **Kejelasan VO:** Whisper pada mix akhir vs Whisper pada VO saja. Mix harus **≥** VO (musik/SFX tidak menutupi kata). Whisper bervariasi ±2–3 kata pada kata pendek/gaul ("nggak"): bila gagal tipis padahal margin per kata lulus, turunkan foley (`FOLEY`) atau musik 2 dB, jangan mengakali gerbang. #003: 118/143 ≥ 116/143.
2. **Timing SFX:** onset pada stem SFX dibandingkan dengan daftar cue di `fullmix.py`.
3. Level pita bicara VO vs latar (dicetak `fullmix.py`) ≥ 10 dB.
Rasa musik dan karakter SFX tetap dinilai user.

## J. Tight Audio Tail ≤ 0,15 dtk (v5.0, untuk auto-replay)
Hening setelah suku kata terakhir dipangkas ≤ 0,15 dtk tanpa fade-out panjang, supaya replay langsung menyambar frame 0 (Circular Reframe Loop, `1-cerita…` §F3). Ambang "terdengar" = tingkat jangka pendek (jendela 10 ms) di atas −45 dBFS setelah VO dinormalkan ke −17 dBFS RMS.
- `kit/audio/vo_tail.py` (`voiced_end`, `trim_tail`: potong ke bunyi terakhir + 0,15 dtk dengan fade cosinus 12 ms agar tidak berdetak).
- `kit/audio/vo_chain.py` memangkas `vo_level.wav` dan mencetak "tail: source … → vo_level.wav … (last audible sound …, tail … ≤ 0.15 s)"; memberi peringatan bila `episode.json` dur lebih dari ±0,5 dtk sesudah bunyi terakhir.
- `kit/tools/line_starts.py` kini menetapkan `dur` = min(durasi file, bunyi terakhir + 0,15 dtk), jadi film berakhir tepat sesudah VO. Episode lama (#004: dur 53,64 dtk, bunyi terakhir 53,42) tidak diubah.
- **Batch #005–#008 (15 Nov 2026), `kit/audio/vo_tighten.py`:** guardrail user = jeda dulu (titik 0,18–0,25, koma 0,10–0,15, elipsis 0,25), **atempo tidak pernah > 1,10**; bila 1,10 belum cukup, durasi dibiarkan lebih panjang (suara natural lebih penting). Temuan: take eleven_v4 Saos Cocol **sudah rapat** (hening sungguhan antar-kalimat hanya ±0,30–0,45 dtk, total hening 4,8–7,6 dtk per take), jadi merapatkan jeda hanya menghemat 0,5–1,8 dtk; durasi ditentukan kecepatan ucapnya. Hasil: #005 56,35 dtk (2,55 kata/dtk, 1,10x, di atas target 55), #006 54,70 (2,66, 1,053x), #007 53,46 (2,50, 1,10x), #008 54,42 (2,65, 1,10x). # Standar Kualitas 10/10 — rubrik penilaian setiap video
Rubrik penilaian film ARSIP Kolase. Dasar: riset niche (`research/niche/`), standar retensi Shorts (safe area 9:16, hook 0–1 dtk) dan prinsip suara Murch (VO nomor satu). Setiap aspek dinilai 1–10; video baru boleh rilis bila **tidak ada aspek di bawah 8** dan rata-rata ≥ 9.

| # | Aspek | Seperti apa 10/10 | Cara cek |
|---|---|---|---|
| 1 | **Hook (0–1 dtk)** | Frame 0 = benda pahlawan besar di tengah, sudah bergerak; stempel/kata hook mendarat ≤ 0,2 dtk; tidak ada fade-in | Still t=0 dibaca dalam 1 detik tanpa suara **dan** gerbang F7 (H1–H7) lulus terukur. Nilai > 8 hanya boleh bila data video sebelumnya ≥ 60% stayed |
| 2 | **Kejelasan cerita per shot** | Satu shot = satu gagasan dari kalimat VO; penonton tahu apa yang harus dilihat (fokus tunggal) | Tes "bisu": tiap still dimengerti tanpa caption |
| 3 | **Komposisi & kepadatan** | Satu subjek per frame, ±5–6 potongan maksimum, subjek y 150–1150, pita caption bersih, tidak ada momen layar kosong | Contact sheet per 1,7 dtk dari render |
| 4 | **Logika gambar** | Gambar sesuai kalimat dan fakta (manusia di uji manusia, jarum mengarah ke subjek, benda realistis); kalimat mirip = visual berbeda; tidak ada gambar yang tak berhubungan | Daftar `2-visual…` §E per shot |
| 5 | **Gerak kertas** | On twos dengan overshoot/settle; bayangan membesar saat terangkat; stempel/slap terasa berat; tidak ada skala/fade halus ala software | Putar 0,25× beberapa shot |
| 6 | **Kamera** | Setiap gerak punya motif (push ke detail, shake di benturan, pull back untuk skala); tetap di atas meja kertas | Tulis alasan tiap gerak kamera dalam satu kalimat |
| 7 | **Editing & transisi** | Pergantian visual tiap 1,5–3 dtk, interval tidak seragam; cut di kata VO; transisi bermakna (freeze→foto arsip, foto→hidup) | Timeline vs timestamp kata VO |
| 8 | **Caption & tipografi** | Sinkron per kata (alignment Whisper), slip hitam 84 px, 1–3 kata, kata kunci amber, pusat y≈1360; teks layar ≥ 40 px, angka dengan figur lining | Cek t0 tiap kata vs `vo_words.json` |
| 9 | **Warna & cetakan** | Palet ARSIP Kolase; merah hanya untuk vonis/angka kunci; stempel kontras dengan latarnya; cetakan arsip bersih (tanpa clip-art/foto modern), lisensi tercatat | Grayscale + `SOURCES.jsonl` |
| 10 | **Suara** | VO jernih di atas segalanya; skor mengikuti emosi per babak; SFX untuk setiap kejadian; −14 LUFS, peak ≤ −1 dBTP; margin per kata ≥ 8 dB | `make_kolase.sh` (ebur128, laporan per kata, Whisper mix = VO) |

## Cara memakai
- Nilai dari **frame** (still di 2–3 titik per panel + contact sheet film penuh) dan **angka** (level audio, loudness), bukan dari ingatan. Jangan menaikkan skor tanpa bukti.
- Prioritaskan faktor besar yang terlihat di ponsel: hook, keterbacaan shot, logika gerak, akting, ritme, caption, kejernihan VO. Detail kecil yang tidak terlihat tidak perlu dikejar.
- Laporkan skor jujur ke user beserta apa yang menahan angka 10.

# 5. Upload dan Thumbnail

## A. Judul (≤ ~50 karakter agar tidak terpotong di ponsel)
Rumus: **kalimat hook VO** + **taruhan nyata** (angka korban/skala) + emoji secukupnya + `#shorts`.
Judul harus jujur dan terbayar oleh isi (lihat standar kebenaran).
Contoh #001: **Banjir Ini Bukan Air… 21 Orang Tewas 😨 #shorts**
Alternatif untuk diuji: "Tsunami Molase Setinggi 15 Meter Menghantam Boston", "Mereka Tenggelam di Gula… Kisah Nyata 1919".

## B. Deskripsi (templat)
```
<kalimat hook>

<tanggal, tempat. 2–3 kalimat fakta inti dengan angka terverifikasi>

<twist: tanda bahaya / ironi, 1–2 kalimat>

<pertanyaan penutup VO> Tulis di kolom komentar 👇

📁 ARSIP KASUS #<nomor> · Mini Thriller IDN: Real Stories. Unexpected Truths.

Sumber:
• <sumber 1>
• <sumber 2>

#shorts #faktaunik #kisahnyata #<wilayah> #<topik> #<tempat> #arsipkasus
```
Cantumkan hanya sumber yang benar-benar dibuka/dicek. Pertanyaan penutup = kalimat terakhir VO (memancing komentar).

## C. Hashtag
Tiga pertama tampil di atas judul: `#shorts #faktaunik #kisahnyata`, lalu hashtag wilayah + topik + tempat, dan `#arsipkasus` (tag seri, selalu).
| Wilayah | Hashtag wilayah yang disarankan |
|---|---|
| True events | `#kejadiananeh #sejarah` |
| Sistem & psikologi | `#psikologi #faktapsikologi #bisnis` |
| Misteri | `#misteri #misteribelumterpecahkan` |
| Keputusan katastrofik | `#bisnis #kesalahanfatal #sejarah` |
| Sains & eksperimen | `#sains #eksperimen` |
| Sejarah & tempat | `#sejarah #tempatmisterius #kotahantu` |

## D. Thumbnail Shorts

# 6. Pelajaran & continuous improvement
Setiap episode menambah baris di sini. Formula, gaya, dan kit hanya berubah bila ada **bukti**: review user, data Studio setelah tayang, atau pengukuran (audio/frame). Satu variabel besar diubah per video agar efeknya terbaca.

## Cara memakai
1. Sebelum menulis script episode baru: baca bagian "Aturan yang lahir dari review" dan "Hipotesis yang sedang diuji".
2. Setelah review user: tambahkan setiap keberatan sebagai aturan umum (bukan hanya perbaikan shot), lalu masukkan ke referensi terkait (1–5) atau ke kit.
3. 7 hari setelah tayang: isi tabel data dari Studio (Viewed vs Swiped Away, APV, engaged views, like/komentar/share/sub); bandingkan dengan episode sebelumnya, bukan dengan angka umum.

### Visual

- Animasi peristiwa tidak boleh terlalu cepat; SFX harus nyambung dengan gerak di layar.

**Data #004 (±11 jam setelah tayang, tangkapan layar Studio 15 Nov 2026 05:21 WIB):** **72,5% stayed to watch** / 27,5% swiped away (#003 47,0%, #002 37,2%; ambang Galloway 70–90% unggul), **average view duration 0:49** dari 53,6 dtk (grafik per jam naik sampai ±1:12–1:48, artinya ada replay/loop), Hype 0, 2 komentar (satu bertanya "13,5 miliar kemana?", sudah dijawab dengan fakta: denda disetor ke kas negara, status pembayaran tidak diketahui). # 7. Selera & cara kerja pemilik channel (dari semua revisi #001–#004)
Dibaca **sebelum** mengirim apa pun ke user (shortlist, script, storyboard, film). Tujuannya agar user tidak perlu mengulang instruksi yang sama. Sumber: review #001 (Molase), #002 (Scroll), #003 (Micin), riwayat commit, dan percakapan 11–13 Nov 2026. Tambahkan baris baru setiap kali user mengoreksi sesuatu yang bersifat selera atau cara kerja.

## A. Selera visual
1. **Kaya dan artistik, bukan "meh".** Bentuk vektor sederhana buatan kode ditolak berkali-kali ("terlalu simpel"). Di #001 yang disukai: tekstur cat, DOF, cahaya, multiplane, wajah ekspresif. Di #003: kolase cetakan arsip asli. Detail harus datang dari bahan nyata, bukan bentuk dasar.
2. **Visual storytelling kuat.** Apa yang diucapkan VO harus terlihat (grafik ASI vs susu sapi → harus ada sapinya). Gambar membawa cerita, bukan dekorasi.
3. **Tapi tidak melelahkan mata.** Layar tidak boleh penuh teks/aset: satu subjek, ±5–6 potongan, teks hanya stempel/label/angka.
4. **Logis dan realistis secara fisik:** tangan memegang HP seperti tangan sungguhan; perangkat lengkap (monitor + keyboard + mouse); arah cahaya masuk akal; jarum suntik mengarah ke tikus; dot botol susu bulat; eksperimen manusia menampilkan manusia.
5. **Tidak ada gambar yang tidak nyambung** hanya karena satu kata cocok (gravir keluarga religius untuk "keluarga Kwok" ditolak).
6. **Kalimat mirip = visual berbeda** (disuntik di shot 11 ≠ shot 15).
7. **Simbol harus jelas maknanya** ("?" milik siapa? taruh di samping orang yang ragu; benda yang disebut harus kelihatan).
8. Latar tidak kosong, ruang berbeda untuk orang berbeda; akhir video harus berupa **aksi yang menutup cerita**, bukan sekadar zoom.
9. Kejadian tidak boleh terlalu cepat untuk dicerna; SFX harus nyambung dengan gerak.
10. **Signature sendiri:** kalau memakai gaya dari luar, ubah palet dan elemen identitas (map ARSIP, stempel) agar jadi milik channel. **Tidak ada watermark/kartu kredit di dalam video.**
11. Representasi Indonesia penting (studi warna kulit sawo matang di gaya lama); untuk benda bermerek pakai kemasan generik tanpa logo.

## B. Selera bahasa & script
1. **Bahasa lisan natural**, bukan bahasa berita/tulis. Contoh koreksi: "uji buta" → "waktu manusia dites tanpa tahu mana yang micin"; "seorang dokter" → "ada dokter"; "kontrol orang tua" ditolak.
2. **Presisi kata:** manusia vs orang, jamak yang benar ("bayi-bayi tikus", "tikus-tikus itu"), istilah resmi ("restoran Tionghoa").
3. **Eksplisit, jangan biarkan penonton menebak** ("koran cuma ingat micin", bukan "koran cuma ingat satu").
4. **Pertahankan punchline lucu yang kuat** ("Jadi lidahmu kenal gurih micin… sejak menyusu"). Jangan dihapus demi memangkas durasi.
5. Taruhan/stakes harus terasa; ironi intelektual saja dianggap dangkal. Jawab "kenapa" dengan mekanisme.
6. Durasi boleh lebih dari 1 menit bila cerita butuh; yang penting cerita tersampaikan.

## C. Cara kerja yang disukai
1. **Riset dulu, berbasis bukti, mendalam** sampai yakin ("100% yakin"); bedakan fakta terverifikasi, inferensi, dan klaim yang diperdebatkan.
2. **Shortlist → user memilih → baru riset** judul terpilih.
3. **Rencana dulu bila arah besar berubah**; untuk hal kecil langsung kerjakan.
4. **Storyboard sebelum render** (hemat token); satu paket review; revisi per nomor shot.
5. **Efisien, tidak sia-sia:** jangan cari/buat aset yang tidak muncul di video; hentikan proses yang macet dan cari jalan lain.
6. **Hemat token tapi kualitas maksimal:** sesi utama effort high; subagen dipilih sesuai kesulitan.
7. **Jangan membuat user mengulang:** cek sendiri daftar A–B dan `2-visual…` §E sebelum mengirim; user lelah memberi instruksi artistik berulang.
8. **Proaktif memperbaiki** ("yang bisa diimprove, improve") dan laporkan apa yang diperbaiki.
9. **Jawab pertanyaan bernomor dengan nomor yang sama**, beri pendapat jujur ("gimana menurutmu?"), boleh membantah dengan alasan.
10. **Fleksibel pada aturan bila masuk akal** (gambar AI boleh bila perlu; video AI tidak), tetapi keputusan yang sudah diambil dihormati.
11. **Pengingat di akhir** bila diminta; merge ke `main` hanya atas izin.
12. **Minim CLI untuk user:** user bekerja dari HP/aplikasi; media di Google Drive per episode (`NNN Judul`); upload YouTube dan ElevenLabs (saat kuota konektor habis) dikerjakan user secara manual. File > 10 MB tidak bisa diunggah Claude ke Drive → kirim lewat chat (preview < 30 MB bila perlu) dan minta user menaruhnya.
13. User yakin persetujuan bisa cepat bila kualitas sudah benar: targetnya **1 video/hari** tanpa putaran revisi panjang.

14. **Shortlist wajib berbasis riset segar, bukan hanya bank ide** (koreksi 14 Nov, #004): tiap kandidat dicek permintaan (autocomplete) dan celah (video Indonesia yang sudah ada) dengan `kit/tools/riset_topik.py`, gratis tanpa API key. vidIQ bisa habis kredit; jangan bergantung padanya.
15. **Sudut Indonesia syarat lulus, bukan nilai tambah:** user menolak cerita yang "gak relate orang Indo" (bohlam/kartel Phoebus ditolak walau fakta kuat). Kandidat tanpa benda/merek/peristiwa yang dikenal penonton Indonesia gugur sebelum shortlist.
16. **Cerita benar, kemasan semaksimal mungkin** (koreksi user 14 Nov, dua kali): bukan "hook jujur yang datar". Fakta tidak boleh salah, tetapi hook, judul, urutan, dan ritme harus mengejar retensi, views, dan potensi viral. Tulis banyak varian hook, pilih yang terkuat, lalu cek kebenarannya. Jangan menolak topik hanya karena kalimat paling aman terdengar datar; kemas ulang dulu.
17. **Janji pilar harus dibayar** (14 Nov, #004): penonton datang untuk "alasan ASLI di balik hal yang kamu kenal"; script wajib punya satu kalimat yang menjawab itu terhadap sesuatu yang penonton alami sendiri (rak warung, harga, tempat), bukan sekadar menceritakan kasus. Tanyakan: penonton nonton untuk apa, dan pulang membawa apa? Kalau tidak terjawab, penonton tidak kembali dan tidak subscribe.
18. **Tanpa jargon yang tidak dijelaskan** (14 Nov): user sendiri tidak tahu KPPU. Setiap lembaga/istilah (KPPU, kasasi, star outlet, wholesaler) dijelaskan dalam ≤ 4 kata yang lucu/lisan ("wasitnya persaingan bisnis") atau dihapus; kepanjangan resmi cukup di layar.
19. **Proaktif mencari celah yang tidak terpikir user** (14 Nov): sebelum mengirim script, cek: jargon, janji pilar, kesan iklan/dibayar merek, kesan kejadian sekarang padahal lama (tahun di layar), keseimbangan (bantahan pihak yang dikritik), pemicu komentar, alasan kembali/subscribe.
20. **Uji POV penonton yang baru lihat** (14 Nov): baca tiap kalimat sebagai orang yang tidak tahu apa-apa dan menonton cepat: siapa melakukan apa ke siapa, akibatnya apa? Kata kerja tanpa objek jelas ("menghukum itu", "naik ke MA", "menang") diganti kalimat lengkap ("Aqua didenda", "membawa kasus ini ke Mahkamah Agung", "denda Aqua berlaku lagi"). Istilah asing diterjemahkan lucu ("alias turunin status warung bintang").

## D. Cek wajib sebelum mengirim storyboard/film (ringkas)
- [ ] Setiap kalimat VO punya gambar yang **menunjukkan** isinya, logis secara fisik dan fakta.
- [ ] Benda yang disebut terlihat; simbol jelas pemiliknya; tidak ada gambar tak berhubungan.
- [ ] Kalimat mirip punya visual berbeda; tidak ada momen layar kosong.
- [ ] ≤ 6 potongan per frame; pita caption bersih; benda kecil tetap terbaca di HP.
- [ ] Bahasa VO/teks natural, presisi, eksplisit; punchline lucu dipertahankan.
- [ ] Tidak ada watermark; kredit gambar tercatat.
- [ ] Perusahaan = pabrik + "pihak X"; lembaga = tokoh konsisten; cap menempel pada pihak yang dikenai; proporsi kepala diukur (#21, #25, #26); keyframe 85% dicek sendiri.
- [ ] Janji pilar dibayar (satu kalimat alasan asli yang menyentuh pengalaman penonton); jargon dijelaskan; tahun di layar untuk kasus lama; tidak terkesan iklan merek mana pun.
21. **Merek = perusahaan, bukan cuma produknya** (review storyboard #004): kalau VO bilang "Aqua didenda/membantah/bebas", yang tampil harus perusahaannya (pabrik berlabel tag ketik + orang berjas "pihak X", wajah generik), bukan botol. Lembaga tampil sebagai metafora orang (KPPU = wasit), konsisten satu tokoh dengan baju sama di semua shot.
22. **Cap/stempel harus terbaca di HP tapi tetap tinta transparan** (bukan kartu): tinta pekat digambar opak (`over=1`, tanpa multiply) + pendar kertas tipis di sekeliling huruf (kit: `bk.stamp(..., legible=True)`; arah hadap dibalik dengan `bk.mirror(name)` → `<name>_m`, bukan sx negatif). Kartu krem ditolak user ("harusnya tetap transparan").
23. **Adegan lucu butuh kontras visual yang jelas** (botol air sendirian di kursi terdakwa ruang sidang megah, zoom dari dekat ke lebar), bukan sekadar benda kecil di depan gedung.

Semua: **subjek konkret yang dikenal penonton di kata 1–3 (benda, merek, tempat, harga, atau peristiwa/hal yang dikenal); inti terucap ≤ 1 dtk; ≤ 10 kata; angka/kapital muncul di layar sejak 0–1 dtk; frame 0 = benda besar yang bergerak.** Kalimat ke-2 (≤ 3 dtk setelahnya) menutup salah paham ("siapa yang bertindak").

|---|---|---|---|

**Hindari sebagai pembuka:** sapaan ("Hai guys"), pengantar tokoh/tanggal ("Pada tahun 1968…"), fenomena tanpa benda dikenal, kata "padahal/tapi" di kalimat pertama, "ternyata" sebagai kata pertama, ringkasan alur ("kalah, menang, kalah") — itu struktur tengah, bukan hook.

**Subjek tidak terkunci ke benda atau merek.** Pilar tetap "alasan ASLI di balik benda, tempat, harga, merek yang kamu kenal, terutama di Indonesia"; peristiwa atau hal yang dikenal penonton boleh bila menarik (data: KLAIM "perang 40 menit" dan WARN "tiga danau di Indonesia" juga menang). ## F. Pola alur yang menahan sampai akhir: jawaban bertahap + loop bertumpuk
1. Pertanyaan hook dijawab **sebagian** di ±15–25% (median pemenang 17%) supaya hook terasa jujur; menunda total memicu swipe karena merasa dikibuli.
2. **Jangan menutup satu loop tanpa membuka loop baru** di kalimat yang sama atau berikutnya ("Tapi Aqua membantah… pengadilan membatalkan").
3. Re-hook di 40–55% berupa pembalikan, bukan tambahan fakta.
4. **Jawaban terbesar (kalimat pilar) dan pembalik terakhir disimpan di 75–90%**: payoff yang lebih akhir berkorelasi positif dengan views (ρ +0,30, n=29) dan sesuai peak-end (Kahneman).
5. **Pertanyaan penonton tidak perlu semua ditulis.** Pemenang rata-rata hanya 1 pertanyaan eksplisit (jumlah pertanyaan tak berkorelasi dengan views, ρ +0,08); loop dibuka lewat kata sambung (tapi, masalahnya, jadi, "why? because"). Tulis pertanyaan eksplisit **hanya di titik yang terdengar seperti akhir cerita** (mis. "Aqua bebas? Belum."), lalu jawab setengah; total 2–3 per video.
6. **Durasi:** Shorts boleh sampai 3 menit, tetapi durasi tidak berkorelasi dengan views di data kita (ρ −0,02; median pemenang 47 dtk). Panjangkan hanya bila cerita butuh (kejadian 45–60 dtk; pilar 40–50 dtk); setiap kalimat tambahan harus membuka atau membayar loop.

# ARSIP Kolase — style prompt (channel style of Mini Thriller IDN, from #003)

> A case file on a paper table. Public-domain engravings, stamps and old prints are cut out with a thin white margin and laid on torn sheets of flat colour; typed slips, ransom letters and red rubber stamps tell the case. Pieces move like cut-out animation, on twos, with paper thickness and real shadows. Vertical, for Shorts.
> Base: lemo-opuscar *Vintage Engraving Collage* (MIT, LemoLab). Base rules stay in force unless changed here; the changes are in [CHANGES.md](CHANGES.md).

## 1. Essence
- **Real printed matter, cut by hand**: engravings, line drawings (Pearson Scott Foresman), anatomy plates, stamps, halftone clippings. Things with no free print (a sachet, a modern package) are printed by us as flat two-ink cut-outs, never with a real logo.
- **The case file**: manila card, typed slips, a red rubber stamp for every verdict. The ARSIP folder opens the case; TERUNGKAP lands on the twist.
- **Paper on a table**: thickness, a shadow that grows with height, a paper back on flips.
- **Cut-out motion**: slide in with overshoot, drop and bounce, slap, swing on a pin, cut and split, stamp. Never a smooth software scale or a fade between pieces.
- **Data engraving** for numbers: engraved bars whose lines swell, amber wash.
Not flat vector illustration, not a slideshow of photos, not 3D.

## 2. Frame and tempo (Formula v4.1)
- 1080×1920. Frame 0 = the hero object, big, centred, already moving; a stamp or ransom word lands in the first 0.2 s.
- A new piece or a new shot every 1.5–3 s. One subject per frame.
- Hero pieces in y 150–1150. Caption band y 1210–1536 stays clear of anything the viewer must read.

## 3. Colour
paper #E6D8BC · card #F3EAD6 · manila #E4C68C · ink #1E1915 · stamp red #B3261E · archive green #2F4F4A · amber #D58E2A · newsprint #E3DDD0.
Red only for stamps, marks and the key number. Never a green stamp on a green field.

## 4. Type and captions
- IM FELL (titles, document heads), Courier Prime (slips, data, captions), Alfa Slab One / Abril Fatface / Oswald / Old Standard in ransom letters (lining digits only). All OFL, in `kit/collage/fonts/`.
- Captions: torn black slip, cream Courier Prime Bold 84 px uppercase, 1–3 words, centre at y 1360; unspoken words dim, spoken words cream, key words amber.
- On-screen labels ≥ 40 px world.

## 5–7. Motion, camera, sound
As the base (§5–§7): on twos, overshoot and settle, hand jitter; rostrum camera push/pull/shake; paper foley (slide, pat, slap, snip, typewriter, stamp thump) and small-ensemble period score; voice ~10 dB over music, master −14 LUFS.

## 8. Native moves
Cut it out · Assemble · Turn the sheet · Through the hole · Ransom and typewriter · Data engraving (base) · **Stamp it** · **Open the file** (ours).

## 9. Pitfalls
Pieces too small for a phone (hero ≥ 45 % of frame width); ink stamps on a field of the same colour; text in the caption band; licence-unknown images; more than ~12 pieces in a frame.

## 10. Engine
`kit/collage/parts.py` (+ `collage_lib.py`) bakes parts; `kit/collage/engine.js` draws them (sprites, poses, slaps, stamps, camera, captions). Each episode: `stories/<slug>/kolase/{bake.py, prints.json, SOURCES.jsonl, film.js}`; storyboard with `node kit/tools/keyframes_2d.mjs stories/<slug>/kolase mid`.

#!/usr/bin/env python3
"""Riset topik gratis tanpa API key: permintaan (autocomplete YouTube ID) + pasokan (video ID yang sudah ada, via yt-dlp).
Pakai:  pip install yt-dlp requests ; python3 kit/tools/riset_topik.py kandidat.json hasil.json
kandidat.json = [{"id":"susu","judul":"...","demand":["susu kental manis","kenapa susu kental manis"],"supply":["susu kental manis bukan susu","bpom susu kental manis shorts"]}]
Aturan baca hasil: lihat research/niche/topik/RUMUS_PEMILIHAN.md"""
import json, sys, time, subprocess, urllib.parse, concurrent.futures as cf
import requests

PREFIX = ["", "kenapa ", "kok ", "alasan ", "rahasia ", "sejarah "]

def autocomplete(q):
    r = requests.get("https://suggestqueries.google.com/complete/search",
                     params={"client": "firefox", "ds": "yt", "hl": "id", "gl": "id", "q": q}, timeout=15)
    return r.json()[1]

def relevant(suggestion, terms):
    """A suggestion is relevant when it contains a whole term (phrase) or every meaningful word (>= 4 letters) of a term, in any order.
    Old filter kept only the first word of each term, so 'lampu merah' matched any 'lampu ...' and 'kental manis' any 'kental ...'."""
    s = suggestion.lower()
    for t in terms:
        t = t.lower().strip()
        words = [w for w in t.split() if len(w) >= 4]
        if t in s or (words and all(w in s for w in words)) or (not words and t and t in s):
            return True
    return False

def demand(terms):
    seen = {}
    for t in terms:
        for p in PREFIX:
            q = (p + t).strip()
            try:
                for s in autocomplete(q):
                    seen[s] = q
            except Exception:
                pass
            time.sleep(0.25)
    return sorted(s for s in seen if relevant(s, terms))

def supply(queries, n=10):
    vids = {}
    for q in queries:
        try:
            out = subprocess.run(["yt-dlp", "--flat-playlist", "-J", f"ytsearch{n}:{q}"],
                                 capture_output=True, text=True, timeout=120).stdout
            for e in json.loads(out).get("entries", []):
                vids[e["id"]] = dict(views=e.get("view_count") or 0, dur=e.get("duration"),
                                     ch=e.get("channel"), title=e.get("title"),
                                     short="/shorts/" in (e.get("url") or ""))
        except Exception:
            pass
        time.sleep(1)
    return sorted(vids.values(), key=lambda v: -v["views"])

def one(c):
    d = demand(c["demand"])
    s = supply(c["supply"])
    v = [x["views"] for x in s]
    return dict(id=c["id"], judul=c["judul"], n_saran=len(d), saran=d[:12],
                n_video=len(s), max_views=max(v) if v else 0,
                n_100k=sum(x >= 1e5 for x in v), n_1m=sum(x >= 1e6 for x in v),
                top=s[:5])

if __name__ == "__main__":
    cands = json.load(open(sys.argv[1]))
    with cf.ThreadPoolExecutor(3) as ex:
        res = list(ex.map(one, cands))
    json.dump(res, open(sys.argv[2], "w"), ensure_ascii=False, indent=1)
    for r in res:
        print(f"{r['id']:10} saran={r['n_saran']:3} video={r['n_video']:2} max={r['max_views']:>9,} >=100k:{r['n_100k']} >=1M:{r['n_1m']}  {r['judul']}")
